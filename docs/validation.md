# Проверки версии 0.1.0

Дата: 30 сентября 2026. Приложение: официальный Windows x64 DeepSeek Harness `0.2.0-rc.2`.

## На работающем приложении

- Языковой пакет подключён штатным `dsh plugin`.
- Главный экран, общие настройки и режимы агента отображаются на русском.
- Меню оболочки «Приложение» и «Правка» и подпись «Высокая» у модели отображаются на русском после патча.
- Проверено переключение English → Русский и сохранение `locale.preference: ru` после перезапуска.
- Главный экран и общие настройки проверены визуально; скриншоты находятся в этой папке. Каждый редкий диалог вручную не проверялся.
- При проверке переключения языка новые ошибки страницы не зафиксированы. Это ограниченная проверка, а не аудит всего приложения.

## Автоматические проверки

Восемь обычных тестов: исходные ключи и подстановки в каталогах, технический идентификатор иллюстраций, исполняемый клиентский пакет, чтение ASAR, неизменность соседних файлов и настроек.

Дополнительно локально выполнен девятый тест на **отдельной копии настоящего исходного `app.asar`**: применение патча, повторное применение, точное восстановление исходной SHA-256 и отказ при неизвестном изменении архива. Все девять тестов прошли. В GitHub Actions этот тест пропускается: бинарник приложения в репозитории отсутствует.

```powershell
$env:DSH_TEST_ARCHIVE = 'D:\test-fixtures\original-app.asar'
npm test
```

PowerShell-скрипты прошли синтаксический разбор. Режим `install.ps1 -CheckOnly` проверен с настоящим встроенным Electron/Node. Полный цикл PowerShell-установщика в рабочем профиле не завершался: управление окном было остановлено пользователем. Рабочая локализация была установлена и проверена до этого; операции патчера проверены отдельно на копии архива.

## Границы проверки

Не проверены другие версии, архитектуры и сторонние сборки, корпоративные запреты на PowerShell, установка без прав записи в папку приложения и работа после будущего обновления DeepSeek Harness. Установщик специально отказывает неизвестному хешу вместо попытки применить старый патч.
